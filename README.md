## 二、下载与安装

本汉化基于 **Shadowrun: Hong Kong - Extended Edition** Steam Windows 版 3.1.2 制作。

1. 前往 [GitHub Releases 页面](https://github.com/toooofu/Shadowrun-Hong-Kong-CN-localization/releases)，下载脚本版安装包 ZIP；
2. 完全退出游戏并完整解压 ZIP；
3. 双击 `安装汉化.cmd`，按提示选择游戏目录；
4. 安装完成后启动游戏。

需要卸载时，完全退出游戏后运行安装包中的 `卸载汉化.cmd`。

### 常见问题

如果无法安装，请依次检查：

- 游戏是否为 Steam Windows 版 3.1.2，且游戏文件未被其他模组修改；
- 运行 `验证安装包.cmd`，检查下载或解压后的安装包是否完整；
- Windows PowerShell 是否为 5.1 或更高版本；
- 如果 PowerShell 版本过低，可在 EXE 安装包发布后改用 EXE 版本安装。

## 三、汉化内容

当前词库共包含 **32,847 条**已完成译文，空译文和模糊词条均为 0：

- 主线战役 `HongKong`：24,303 条；
- 奖励战役 `hk_coda`：7,641 条；
- 程序界面与运行时文本 `code`：900 条；
- 共享核心内容 `shadowrun_core`：3 条。

补丁覆盖主线剧情、奖励战役、任务对话、物品与技能说明、人物创建、难度、载入、物品栏及主要程序界面，并补齐中文显示所需字体。

当前版本**不包含**开场及过场 OGG 动画、PNG 图片、场景贴图、招牌、海报等图片或多媒体内容中的文字汉化，因此少量美术文字仍会显示英文。

## 四、字体方案

中文字体采用开源的 **Noto Sans SC**：常规界面使用 Medium 字重，粗体界面使用 Bold 字重。补丁对游戏中的 14 套中文位图字体图集进行重绘，同时覆盖原有汉字、中文标点及新增缺字。

重绘时保持字形原始宽高比，将统一字面框居中放入游戏原有槽位；只有字形超出槽位时才进行整体等比缩小，不做横向拉伸，从而减少部分汉字被压窄的问题。英文、数字、原有排版参数和 UI 材质保持不变。

- **GPT-5.6 Terra（High）子 Agent**：负责按区块进行文本分片翻译与批量整理；
- **GPT-5.6 Sol（High）子 Agent**：负责独立语义审校、关键剧情复核、统一术语、润色及最终 LQA。

机器辅助用于提高处理效率，译文经过分片复核、结构校验和实机测试，并保留持续修订与校对流程。
