当前版本尚未经过全流程完整测试，仅在游戏中进行了基础验证，可能仍存在漏译、错译、排版或兼容性问题，欢迎通过 GitHub Issues 提交截图、场景名称和复现步骤。

## 二、下载与安装

**适用游戏版本：Steam Windows 版 3.1.2（Steam Build ID 993355）。** 其他版本或被模组修改过的游戏文件可能无法安装；安装器会在文件哈希不匹配时停止，不会强行覆盖。

请前往 [GitHub Releases 最新版本](https://github.com/toooofu/Shadowrun-Hong-Kong-CN-localization/releases/latest) 下载完整补丁 ZIP 及对应的 SHA-256 校验文件。不要下载 GitHub 自动生成的“Source code”压缩包，它不包含可安装资源。

1. 确认游戏为 Steam Windows 版，并完全退出游戏。
2. 完整解压下载的补丁 ZIP。
3. 可先双击 `验证安装包.cmd` 检查文件完整性。
4. 双击 `安装汉化.cmd`。
5. 使用安装器自动找到的游戏目录，或手动选择 `Shadowrun Hong Kong` 游戏根目录。
6. 安装成功后启动游戏。

需要卸载时，完全退出游戏后运行安装包中的 `卸载汉化.cmd`，安装器会恢复并校验原始文件。

## 三、汉化内容

当前词库共包含 **32,847 条**已完成译文，空译文和模糊词条均为 0：

- 主线战役 `HongKong`：24,303 条；
- 奖励战役 `hk_coda`：7,641 条；
- 程序界面与运行时文本 `code`：900 条；
- 共享核心内容 `shadowrun_core`：3 条。

补丁覆盖主线剧情、奖励战役、任务对话、物品与技能说明、人物创建、难度、载入、物品栏及主要程序界面，并补齐中文显示所需字体。

当前版本**不包含**开场及过场 OGG 动画、PNG 图片、场景贴图、招牌、海报等图片或多媒体内容中的文字汉化，因此少量美术文字仍会显示英文。

## 四、字体方案

中文字体采用开源的 **Noto Sans SC**：常规界面使用 Medium 字重，粗体界面使用 Bold 字重。补丁对游戏中的 14 套中文位图字体图集进行重绘，同时覆盖原有汉字、中文标点及新增缺字。

重绘时保持字形原始宽高比，将统一字面框居中放入游戏原有槽位；只有字形超出槽位时才进行整体等比缩小，不做横向拉伸，从而减少部分汉字被压窄的问题。英文、数字、原有排版参数和 UI 材质保持不变。

## 五、制作方式

本汉化基于 OpenAI Codex 完成：

- **GPT-5.6 Sol（High）**：负责整体方案规划、技术路线、文本提取、补丁构建与技术支持；
- **GPT-5.6 Terra（High）子 Agent**：负责按区块进行文本分片翻译与批量整理；
- **GPT-5.6 Sol（High）子 Agent**：负责独立语义审校、关键剧情复核、统一术语、润色及最终 LQA。

机器辅助用于提高处理效率，译文经过分片复核、结构校验和实机测试，并保留持续修订与校对流程。
